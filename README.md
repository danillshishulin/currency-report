# Отчёт по курсам валют

## Что делает
Программа загружает курсы валют с сайта ЦБ РФ, считает изменение за день,
определяет статус каждой валюты и сохраняет отчёт в Excel.

## Валюты
USD, EUR, CNY, GBP, JPY

## Возможности
- загрузка данных с сайта ЦБ
- Расчёт изменения курса за день
- Сортировка по изменению
- Фильтрация выросших / упавших / не изменившихся
- Сводка по количеству валют в каждой категории
- Сохранение в Excel с датой в имени файла

## Технологии
- Python 3
- pandas
-openpyxl (для Excel)
- datetime
